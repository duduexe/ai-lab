# Video animation, effect and style library

320 ready-to-use ideas for short vertical videos (1080 x 1920): text animations, transitions, effects, graphics, filters, lights and video styles. Each item has a plain description, when to use it, and a prompt you can give to Claude (chat or Claude Code) to make it from scratch. This file is text only: no pictures, fonts or sounds.

## How to use it
1. **Copy one prompt:** pick an item, copy its prompt and paste it into Claude.
2. **Give Claude the whole library:** attach this file and say "Use this library to make a video with the Punch-in zoom and the Marker line".
3. **Make it yours:** no colours or fonts are set. Tell Claude yours once, or let it choose.

## How Claude should build an item
Make it with code, for example Remotion (React video), or HTML, CSS and JavaScript recorded to video, as a layer for a 1080 x 1920 vertical video at 30 fps. Use the timings and sizes in the prompt, your own colours and fonts, and keep text away from the app buttons (right side and bottom of the screen). Things that float over the footage come in and go out softly. Check a few frames before calling it done.
