# Dudu Experiments' Reel Library

Text animations, transitions, effects, graphics, filters, lights and video styles for short vertical videos (1080 x 1920). Every item has a live preview, what it does, when to use it, and a prompt to make it from scratch with Claude.

- **How to use it:** the guide page of the site (`#how-to`) explains how to make a reel with Claude step by step, with prompts to start with.
- **Look and copy:** open the site, search or browse the categories, hover a card to see it move, click it for the details and press **Copy** on the prompt.
- **Download everything:** `library.md` is one text file with every item (no pictures). Give it to Claude and ask for the items you want.
- **Skill for Claude:** `skill/video-animation-library` (also `video-animation-library-skill.zip`). Put the folder in `~/.claude/skills/` for Claude Code, or upload the zip as a skill in Claude.

The site is static: any web server works (for example GitHub Pages). Opening `index.html` straight from the disk does not work, because the page loads its library text and media files.
