Dudu Editor: edit your reels with Claude

A free video editor for reels, TikToks and Shorts that runs on your own Mac. Describe your video, Claude writes the storyboard and builds the montage on a real timeline, then you change anything by hand or by asking. Over 350 animations and effects inside, and it learns your style as you go.

You need a Mac and a Claude plan with Claude Code (Pro or higher). No API key, nothing else to pay. The editor speaks English and French.

Download the editor ZIP from GitHub, about 26 MB See the editor on GitHub github.com/duduexe/dudu-editor

Or let Claude set it up

In the Claude desktop app, open Code, choose your home folder and paste one of these. Claude downloads the editor and asks you before each install.
